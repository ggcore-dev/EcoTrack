# 🌿 EcoTrack

### Daha bilinçli yaşam, daha sürdürülebilir bir gelecek.

EcoTrack, günlük çevre dostu alışkanlıkları takip etmeyi ve doğal kaynakları daha bilinçli kullanmayı kolaylaştırmak için geliştirilen Türkçe bir web uygulamasıdır.

## ✨ Özellikler

- 🌱 Çevre dostu görevleri takip etme
- 💧 Su tüketimi kayıtları
- ⚡ Enerji tüketimi kayıtları
- 🎯 Kişisel hedefler belirleme
- 📊 İlerlemeyi takip etme
- 💾 Tarayıcıda veri saklama
- 📱 Farklı ekran boyutlarına uyumlu arayüz

*Not: Özelliklerin kullanılabilirliği uygulamanın mevcut koduna bağlıdır.*

## 🚀 Kullanım

Web sitesini aç ve sunulan özellikleri kullanmaya başla. Desteklenen kayıtlar, uygulamanın tarayıcıdaki yerel depolama alanında saklanabilir.

## 🛠️ Kullanılan teknolojiler

- HTML5
- CSS3
- JavaScript

[EcoTrack'i ziyaret et](https://ggcore-dev.github.io/EcoTrack/)

## 🔒 Gizlilik

Kayıtların saklanma şekli uygulamanın koduna bağlıdır. Hassas bilgileri herkese açık depolara eklemeyin.

## 🎯 Amaç

Çevre bilincini artırmak, sürdürülebilir yaşam alışkanlıklarını desteklemek ve teknolojiyi toplumsal fayda için kullanmak.
